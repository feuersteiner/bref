# Bref

**[Live Demo](https://feuersteiner.github.io/bref/)**

Bref is being reset for v1 as a Svelte 5 UI component library. This release establishes the package tooling and intentionally exposes no public components or CLI commands yet.

## Installation

```sh
npm install bref-ui
```

## Current status

The v1 root module intentionally has an empty public API while foundations and components are rebuilt. The `bref` binary is installed for future tooling, but it currently has no commands.

Use the [live demo](https://feuersteiner.github.io/bref/) to follow the work in progress.
